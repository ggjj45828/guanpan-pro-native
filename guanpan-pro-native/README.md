# 观盘 Pro · SwiftUI 原生重写

这是观盘 Pro 的 SwiftUI 原生重写工程。原有 HTML 与 Capacitor 工程保留，不会覆盖。它目前是迁移中的原生源码基线，不是可安装的 IPA，也没有经过 Xcode 编译或真机验证。

按用户要求，单只估值体检和未来现金流预测不包含在当前原生工具页中。


本次原生体验修订：自选按六位代码自动识别名称；行情详情默认显示腾讯当日分时并在前台约 15 秒尝试更新，优先试用已配置 NAS 的分钟代理，失败时回退 iPhone 直连；日K支持捏合缩放和横向拖动。基金持仓优先显示，净值图支持 1 月/3 月/半年/1 年/全部区间及点选读数；场外基金不再提供新分红录入入口，分红日历仅显示 ETF，旧基金流水保留；已移出基金历史支持左滑删除并二次确认。工具页已移除迁移进度清单，新增针对全部自选/持仓的本地量化扫描排序；单标的详情内另有 AI 分析、规则检查及策略回测入口。输入表单提供键盘收起按钮；主题、内置背景、自定义背景保留，并新增背景遮罩透明度调节。腾讯行情直连或 NAS 分钟路由是否可用需在 iPhone 网络下验证，失败时不伪造数据。

主界面按 iPhone 使用习惯重新组织为五个底部入口：总览、ETF、基金、资产、更多。总览突出显示总资产与盈亏，行情、自选和提醒集中在首页；分析工具和设置从“更多”进入，避免底部导航拥挤。金额卡片支持窄屏缩放，使用系统材质标签栏、圆角信息卡和标准导航层级。整体样式借鉴 iOS 系统应用的导航与信息层级，不复制单一第三方应用；最终屏幕适配仍需在 Xcode 模拟器和真机验证。

原生工具页提供月度投资复盘（汇总本月交易、分红、费用及已有账户快照）、本地规则账户提示（仓位上限、现金占比、基金报告重叠及赎回费估算）和全账户 AI 建议入口；持仓页也提供账户提示入口。基金页可逐只核对已确认流水的净份额与当前持仓，发现差异时只提示，不自动重算或覆盖未录入老仓。估算赎回费可按平台实际费用或到账核对，修正已实现盈亏；联动现金会按差额校正。旧网页 `feeEst` 标记会迁入。单标的 AI 分析会附带所选日期已有的分时采样（最多 180 点）、日线和完整日线计算的支撑压力参考；不会补造缺失数据。以上只读取本地记录，不产生交易指令或确定性预测。
