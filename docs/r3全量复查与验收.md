本文件覆盖 88 项需求矩阵和本轮新增要求。代码存在、自动测试通过、Apple 运行测试通过、NAS 实际部署是不同的验收层级；每项按现有证据标注，不以计划或接口占位代替功能完成。

## 最新代码与构建

最新 iOS/NAS 源码以候选分支 `upgrade/v2.13.55-r2` 为准。当前工作区还修改了 UI、研究功能和场外历史归档保护；这些修改须在后续 Apple 构建完成后才能标为已验收。当前版本号为 2.13.55（build 60）。

## 自动化验证

工作区 Python/Node 离线套件实际通过 **82 项 JavaScript 测试、49 项 Python/NAS 测试**及合成示例；另有 NAS 更新 ZIP 的 18 个文件清单/校验和与 9 个本地 HTTP 路由 smoke test。自动测试只使用合成数据和临时目录。最终 Apple 验收须记录当前最后提交对应的构建、单元测试、UI 测试数与截图；本机 Windows 不含 Xcode。Docker 引擎未启动，因此不声称本次完成 Docker build。

## NAS 更新步骤

使用交付的 `观盘Pro-NAS-v2-更新包.zip`。先备份旧服务配置和完整 `data/`，在新目录用默认 8789 端口并行启动，确认 `/api/ping`、`/api/native/ping`、三条 v2 状态/行情查询路由和新 iOS 连接后，再安排切换 8788。回滚时恢复旧代码和旧数据目录；不要将 v2 数据库覆盖到旧库。更新包不包含数据库、真实持仓、配置口令或用户密钥。

## 状态定义

- **已测试**：测试实际运行且通过，测试日志可复查。
- **已实现/待实机**：代码及离线接口已经存在；依赖 Apple 设备、数据源或 NAS 部署的部分仍未验证。
- **未实现**：没有可以运行的实现。

完整 GP-001–GP-088 逐项记录见同目录 `完整需求矩阵.md`。GP-081 以当前要求为准：停止场外业务，先验证完整归档；用户确认备份有效前不得清理历史。截图所列的十项验收补充另见《代码与验收补充审计》。
