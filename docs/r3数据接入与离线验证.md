# 可配置数据接入与离线运行

用户当前没有数据服务。系统可以读取用户合法取得的标准化数据，缺失数据明确显示，不预置伪行情。

NAS 配置 `V2_FEED_URL` 可接入标准化 JSON 服务；外网必须 HTTPS，本机可 HTTP。`V2_FEED_TOKEN` 仅通过服务器环境传入，不写进研究文档。设 `V2_UPSTREAM_ENABLED=0` 可关闭原有外网采集适配。五档供应商数量换算必须显式设置 `V2_BOOK_VOLUME_MULTIPLIER`，默认空，不猜手数与股数。

接口 `POST /api/v2/market/ingest` 需要 NAS 同步口令（若已配置），请求内容为 `{records:[], universe?:{}, financials?:[]}`。金额/行情价格为 1/10000 元整数，数量为股，时间为 UTC 毫秒。`records` 每批最多 10000 条。行情 quote/intraday/daily/book/fundamentals 必须带 symbol、asset（etf/stock）、at、availableAt、source、data；价格事件不得在当时尚未知晓。book 必须确认 `quantityUnit=shares`，只接受有效盘口，不用最低价触及伪造成交。

证券池 `universe`：source、asOf、scope（provided 或 full-market）、expectedCount、instruments[{symbol,asset}]。full-market 必须提供与 expectedCount 数量一致的清单和 `providerConfirmsComplete:true`。这仅是提供方的清单声明；系统还检查当前五分钟内报价覆盖，缺少时不显示完整行情覆盖。行情覆盖与基本面完整度分别报告，不把清单存在当作基本面齐全。一个 asOf 版本不能被不同清单静默覆盖。

`GET /api/v2/market/universe` 查看覆盖；`GET /api/v2/market/research-page?offset=0&limit=50` 获取分页研究快照，每页最多 100 个标的。证券池独立于用户持仓。App 当前研究仍默认分析实际提供的快照；分页接口可供后续全量雷达接入，不声称移动端已完成完整市场持续扫描。

financials 用于从用户提供的年度财报与估值计算因子，字段：symbol、asset=stock、source、price（元）、reports[]、valuations[]。reports 每行含 period=annual、periodEnd、publishedAt、dividendPerShare（元/股）、eps（元/股）、netProfit、operatingCashFlow、freeCashFlow。valuationMetric 为 pe 或 pb，valuations 每行含 at、availableAt 和对应数值。只采用当时已公布报告；至少三期年度分红计算稳定性，至少二十个不同历史日期计算估值分位。现金流质量为经营现金流/净利润截断至 0–1，分红稳定性为 1−变异系数截断至 0–1，股息率为最新年度每股分红/输入价格。方法标为 annual-pit-v1，属于可解释研究指标，不是审计评级或收益保证。缺少数据不填默认分数。ETF 的穿透基本面须由合法数据源独立提供，不把公司 EPS 套给 ETF。

已公告分红使用 kind=dividend，at=recordAt，data 含 id、publishedAt、recordAt、paymentAt、netPerShare（税后每股 1/10000 元）；公告时间不晚于捕获时间，捕获时间不晚于登记日。登记日晚于初始实验时点才自动处理。按登记时点原持仓与成交流水重建权益，支付进入收益流水，不计外部本金。未来未公布分红不预测成确定收入。

离线运行：安装 Python 3.10+ 后，在源码根目录执行：

```text
python nas-sync-server/offline_market.py --input your-bundle.json --data-dir work/offline-data --report work/research-report.json
```

该命令不访问网络，仅读入指定文件，使用单独 channels-v2.sqlite3/market-v2.sqlite3，绝不打开真实 sync.sqlite3。测试使用 tests/test_research_inputs.py 的合成资料；合成资料不混入生产。

T+0/T+1 按每只证券确认。上交所说明：[跨境 ETF 二级市场可当日回转](https://etf.sse.com.cn/fund/learning/knowledge/c/5704994.shtml)、[ETF 交易规则分类](https://www.sse.com.cn/assortment/fund/etf/question/c/c_20240118_5734755.shtml)。本系统只模拟二级市场买卖，不把基金申购赎回的交收规则混用。
